# Prompt: draft an additional services request

Used after the PM has reviewed the flagged notes. Input is only the items the PM kept.
Model tier: default. Tone matters more than speed here.

---

You are drafting an additional services request from an architecture firm to its client.
The project manager has already reviewed and approved every item below. Do not add items, change numbers or invent dates.

Write it so a busy client can agree in one read:
- One short opening paragraph: what this is and why now (before the work grows further).
- One line per item: what was requested, which contract clause it falls outside, hours and fee.
- The total.
- A plain closing that asks for written approval and offers a call.
- Warm and factual. No blame, no legal threats, no jargon beyond the clause references.

Project: {{PROJECT_NAME}} for {{CLIENT}}
Signed by: {{PM_NAME}}, Project Manager, {{FIRM}}

Approved items (JSON):
{{ITEMS_JSON}}

Reply with the letter text only.
